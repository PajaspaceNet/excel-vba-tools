# excel-vba-tools
A collection of VBA scripts for Excel automation 

## Jak to použít OCISLOVANI VIDITELNYCH sloupcu tabulky
### Script OCISLUJE POUZE VIDITELNE SLOUPCE
1. **Otevřete editor:** V Excelu stiskněte klávesovou zkratku **Alt + F11**.
2. **Vložte kód:** V horním menu zvolte **Insert -> Module** a do prázdného okna vložte kód skriptu.
3. **Vyberte list:** V levém panelu (Project Explorer) klikněte na list, ve kterém chcete skript spustit.
4. **Označte oblast:** Vraťte se do tabulky a myší označte oblast (např. buňky v záhlaví), kterou chcete očíslovat.
5. **Spusťte skript:** Vraťte se do okna s kódem (VBA editor) a stiskněte tlačítko **Run** (zelený trojúhelník v horní liště).

**Výsledek:** Skript okamžitě očísluje pouze **VIDITELNÉ** sloupce ve vašem výběru a ty skryté přeskočí.
